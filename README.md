# Beautiful Animated Landing Page

A stunning, dark-themed landing page featuring smooth animations, interactive elements, and modern design.

## Features

- 🎨 **Dark Theme** - Elegant dark color scheme with purple/pink accents
- ✨ **Animated Background** - Dynamic floating gradient orbs and particles
- 🚀 **Framer Motion Animations** - Smooth, professional animations throughout
- 📱 **Fully Responsive** - Perfect on all devices and screen sizes
- 🎯 **Interactive Elements** - Hover effects, transitions, and micro-interactions
- 💎 **Glass Morphism** - Modern glassmorphic UI components
- 🔥 **Performance Optimized** - Fast loading and smooth animations

## Tech Stack

- **React** - UI library
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **React Icons** - Icon library

## Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Project Structure

```
src/
├── components/
│   ├── AnimatedBackground.jsx  # Animated background with orbs & particles
│   ├── Hero.jsx               # Hero section with CTA
│   ├── Features.jsx           # Feature cards with icons
│   └── Footer.jsx             # Footer with social links
├── App.jsx                    # Main app component
├── main.jsx                   # Entry point
└── index.css                  # Global styles & animations
```

## Customization

- **Colors**: Modify gradient colors in component files and Tailwind config
- **Animations**: Adjust animation durations and effects in index.css and components
- **Content**: Update text, icons, and features in component files
- **Layout**: Customize spacing and layout using Tailwind utilities
